# Repository rules

- Public files must contain only framework material and fictional sanitized examples.
- Never read, print, commit, or publish credentials, cookies, tokens, API keys, private configuration, real absolute paths, usernames, host names, or personal experience records.
- Before any private experience-library write, show the proposed path and content, then obtain explicit approval.
- Native Agent Memory is optional and may store only a short non-sensitive pointer to a verified private asset; it is not a fact source.
- Use Python standard library only for repository scripts and keep commands compatible with Windows, WSL, and macOS.
- Do not create remotes, push, publish, install tools or Skills, or change user-level Agent settings without explicit user authorization.
